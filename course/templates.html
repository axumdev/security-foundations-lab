Evidence file naming

Use names such as week16-LAB016-suricata-alert-2026-10-15T140000Z.json. Keep screenshots tightly cropped around relevant output. Never include passwords, private keys, cloud tokens, personal messages, or unrelated logs. A screenshot is useful context; preserve machine-readable output too when it matters.
