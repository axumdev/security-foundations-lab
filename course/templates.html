Evidence file naming

  1. Use names such as week16-LAB016-suricata-alert-2026-10-15T140000Z.json.
  2. Keep screenshots tightly cropped around relevant output.
  3. Never include passwords, private keys, cloud tokens, personal messages, or unrelated logs.

A screenshot is useful context; preserve machine-readable output too when it matters.
