Week 02 / Foundations

Build your first Linux VM

6 hours core+ 0–6 hours practicePrerequisite: Week 01

An ISO is installation media, similar to a virtual DVD. A VHDX is a guest disk stored as a host file. A dynamically expanding disk grows as data is written, up to its configured limit. Ubuntu Server has a terminal rather than a desktop; this reduces memory use and teaches the underlying system.

Power-on plan: UBU01 only: 2 vCPU, 2 GB fixed RAM, 40 GB dynamic VHDX.

Your week: Session A (2 h): read, prepare, begin the first steps. Session B (2 h): finish the build and tests. Session C (2 h): troubleshoot, write evidence, and complete mentor review. These are planning estimates; use extra hours for repeats. If a gate fails, carry it forward before dependent labs.

1. Download the right installer

From the Ubuntu 24.04 release directory linked below, download the current 24.04.x live-server amd64 ISO into C:\CyberLab\ISOs. Use amd64 even though the processor is Intel. Record the exact filename, date, download URL, and version in versions.txt. Download SHA256SUMS from the same HTTPS release directory. In PowerShell run Get-FileHash with the exact local ISO path and compare every hash character with its SHA256SUMS entry. A hash comparison detects corruption; a signed checksum verified with a trusted signing key adds stronger origin verification.

2. Create UBU01

Hyper-V Manager → select the host → New → Virtual Machine. Name: UBU01. Store it under C:\CyberLab\VMs. Select Generation 2. Set startup memory 2048 MB and clear Dynamic Memory. Choose Default Switch for temporary internet access. Create a new 40 GB VHDX. Select “Install an operating system from a bootable image file” and browse to the ISO. Finish. Right-click UBU01 → Settings → Processor → 2. Under Security, keep Secure Boot on and select Microsoft UEFI Certificate Authority, the Linux-compatible template.

3. Install into the virtual disk

Connect → Start. Press a key if prompted to boot the DVD. In the Ubuntu installer choose English, the correct keyboard, Ubuntu Server, and automatic DHCP networking. Leave proxy blank unless your network requires one. Accept a working mirror. Choose “Use an entire disk” only after verifying this is the 40 GB virtual disk inside UBU01. For simplicity clear LVM if offered. Confirm the guest-disk changes. Enter your name, server name ubu01, username learner, and a unique password. Enable Install OpenSSH server. Skip optional featured snaps and Ubuntu Pro enrollment. Finish installation, eject the ISO through VM Settings → DVD Drive → None if needed, and reboot.

4. Learn the terminal

Sign in as learner. Password typing shows no characters; this is normal. Commands are case-sensitive. Type one line at a time. The # symbol starts a comment; $ shown in websites is often a prompt, not part of the command.

Ubuntu guest • Bash
whoami
hostname
pwd
ip -br address
free -h
df -h /
cat /etc/os-release

Expect learner, ubu01, your home directory, an IPv4 address, about 2 GB memory, and Ubuntu 24.04. Record actual values rather than copying expected output.

5. Update and prepare tools

Ubuntu guest • Bash
sudo apt update
sudo apt upgrade
sudo apt install openssh-server curl wget nano git jq dnsutils tcpdump nmap nginx ufw rsyslog auditd openssl python3
sudo systemctl enable --now ssh
sudo systemctl status ssh --no-pager

sudo runs a command with administrator privilege and may ask for your learner password. apt update refreshes package information; apt upgrade installs newer packages. Read prompts before accepting. If a reboot is needed, run sudo reboot and sign back in. Tool downloads require internet; the reading material does not.

6. Save a clean recovery point

In the guest run sudo poweroff. In Hyper-V Manager verify Off, then right-click UBU01 → Checkpoint. Rename it w02-clean-linux. A checkpoint depends on the VM’s disk chain; it is not an independent backup. Start the VM and verify you can log in. Keep only a few named checkpoints; delete old ones through Hyper-V Manager, never by deleting AVHDX files in Explorer.

Pass this week

  • Version and hash record
  • Guest identity, IP, memory, disk, and SSH service output
  • Clean Linux checkpoint and successful reboot

Explain without the guide

  • What is the difference between the ISO and VHDX?
  • Why does sudo ask for your password?

If something fails

No boot: check DVD boot order and Linux Secure Boot template. No address: confirm Default Switch and DHCP. apt lock: wait for the updater to finish; do not delete lock files. SSH status exits with q if it opens a pager.

Optional practice · 0–6 extra hours

Use man ls and man systemctl. Practice searching with / and exiting with q.
