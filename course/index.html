Build your first security lab.

Start with one laptop. Build a Linux guest, connect a second machine, and capture a request. Later, use those same systems to investigate an incident.

Start Week 1: Prepare your laptop →

Choose your setup

Windows 11 Pro with Hyper-V: follow the documented course path.

No Hyper-V? On a supported Intel or AMD computer, try the VirtualBox guide for Weeks 1–3. This alternative is in development and has not yet been tested end to end.

Before you begin

Your equipment

The guide assumes Windows 11 Pro, 16 GB of RAM, and administrator access. Week 1 checks your hardware before you install a VM.

Your pace

Allow about six hours per core week. Split a lesson across sessions; use the checks at the end to decide when to move on.

Using the download? Keep the extracted folder together. Reading works offline. You’ll need internet for installers, updates, and cloud exercises.
