Week 07 / Systems

Windows administration and event evidence

6 hours core+ 0–6 hours practicePrerequisite: Week 06

Windows uses security identifiers, access tokens, groups, services, and access-control lists. The GUI and PowerShell are two ways to inspect the same system. Event IDs are meaningful only with their provider, channel, time, and context.

Power-on plan: WIN01 only: Windows Server 2025 Evaluation Desktop Experience, 4 GB RAM, 2 vCPU, 60 GB disk. Other VMs off.

Your week: Session A (2 h): read, prepare, begin the first steps. Session B (2 h): finish the build and tests. Session C (2 h): troubleshoot, write evidence, and complete mentor review. These are planning estimates; use extra hours for repeats. If a gate fails, carry it forward before dependent labs.

1. Install the Windows practice machine

At the Microsoft Evaluation Center download the Windows Server 2025 ISO to the host ISOs directory; registration may be required. Read evaluation terms and record the install/expiry dates. This is evaluation software, not open source. A host Windows license does not automatically license guests. Create WIN01 in Hyper-V using Generation 2, 4096 MB fixed memory, 2 processors, 60 GB dynamic disk, Default Switch, and the ISO. Use the Microsoft Windows Secure Boot template.

2. Complete setup carefully

Boot the guest ISO and select language/keyboard → Install. Choose Windows Server 2025 Standard Evaluation (Desktop Experience), accept terms, select Custom installation, and install onto the empty 60 GB guest disk. Do not select an edition without Desktop Experience. Set a unique Administrator password. Use VM Connection → Action → Ctrl+Alt+Delete to sign in. Install updates and activate the evaluation as directed by Microsoft while in update mode. Download Sysmon from Microsoft’s official page inside WIN01, extract to C:\Tools\Sysmon for Week 13, and retain the original download.

3. Set identity and private networking

WIN01 • administrator Windows PowerShell
Rename-Computer -NewName WIN01 -Restart

After reboot, shut down and switch WIN01 to CyberLab-Private. Start it, run ncpa.cpl, right-click the connected Ethernet adapter → Properties → Internet Protocol Version 4 → Properties. Set IP 10.77.0.21, mask 255.255.255.0, and leave gateway/DNS empty for now. Confirm with ipconfig /all. Do not change the real laptop’s adapter.

4. Create a standard identity

WIN01 • administrator PowerShell
$labPassword = Read-Host "Choose a unique lab password" -AsSecureString
New-LocalUser -Name labuser -Password $labPassword
Add-LocalGroupMember -Group Users -Member labuser
Get-LocalGroupMember -Group Administrators
Get-LocalUser

labuser must not appear in Administrators. Sign out and sign in as .\labuser once, then return to Administrator. Record which operations requested elevation. Keep Defender and Windows Firewall enabled.

5. Test a Windows file boundary

Create C:\LabData\case.txt containing dummy information. Right-click LabData → Properties → Security → Advanced. Disable inheritance and choose to convert inherited permissions. Preserve SYSTEM and Administrators full control. Remove ordinary Users/Authenticated Users entries if present; add WIN01\labuser with Read & execute. Apply to this folder/subfolders/files. As labuser, prove reading succeeds and editing case.txt fails. Return to Administrator and inspect:

WIN01 • administrator PowerShell
icacls C:\LabData
Get-Service | Select-Object -First 10
Get-NetTCPConnection -State Listen | Select-Object -First 15

6. Find actual events

Open Event Viewer → Windows Logs → Security. Look for a recent successful sign-in (4624) and inspect its details, including logon type. Do not assume all 4624 events represent someone typing at a keyboard.

WIN01 • administrator PowerShell
Get-WinEvent -FilterHashtable @{LogName='Security';Id=4624} -MaxEvents 5 | Format-List TimeCreated,Id,Message

If the event is absent, inspect audit policy with auditpol /get /category:* rather than manufacturing evidence. Export relevant events with Save Selected Events into the guest C:\LabEvidence folder, which you create first.

Optional practice · 0–6 extra hours
