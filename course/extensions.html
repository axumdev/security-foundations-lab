Advanced practice / six guided modules

Follow the evidence across security platforms.

Add 36 planned hours to the 156-hour core.

Wazuh remains the core stack. These extensions teach Elastic/ELK, Splunk, and Security Onion without requiring all of them to run together. Each module has three two-hour sessions: prepare/build, investigate/test, then troubleshoot/document/review.

Installation delays may require additional practice time.

16 GB laptop rule: One security appliance at a time. Elastic: 8 GB; Splunk: 6 GB; Security Onion Import: 8 GB. Shut down all other guests. Keep 50 GB of host disk headroom and account for dynamic disks, ISOs, and checkpoint growth. Full Security Onion Standalone is a later mentor-hardware exercise.

Shared case and source boundaries

Download CASE-M01: 16 synthetic normalized events plus a 32-packet HTTP capture. Elastic and Splunk receive the same event file; Security Onion receives only the four HTTP transactions in the PCAP. Wazuh results come from the existing core labs. The answer key is included for mentor review. This case validates file parsing and investigation; the core labs provide live collection experience.

Mentor assessment

Score each module out of 10: safe/correct setup (2), reproducible positive and negative tests (3), explanation of evidence and blind spots (3), and clean handover (2). Advance at 8/10 with no unresolved unsafe exposure or false claim of evidence.

Keep configuration, queries, version/license notes, results, troubleshooting notes, and cleanup proof.

E6 is the extension capstone.

Baseline answer key: six failed logins for trainee01, two successful logins total, four HTTP requests with two 404s, one harmless command marker.

Repeated failures followed by a success merit review but do not establish unauthorized access.

No malware or exfiltration is demonstrated.
